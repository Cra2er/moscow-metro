# Moscow Metro

Интерактивная схема метро на D3.js 7.9.0. Размер кружков и светлота независимо кодируют показатели станций; доступны прямая и обратная зависимости. Публикация — GitHub Pages.

## Локально

Откройте `dist/index.html` в браузере либо выполните `python3 -m http.server 8080 --directory dist`. Зависимости и данные локальны; сборка и сервер приложению не нужны.

## Публикация

Репозиторий: `moscow-metro`, основная ветка `main`. В Settings → Pages выбрать Source: GitHub Actions. Workflow `.github/workflows/pages.yml` публикует папку `dist` при push в `main`. Относительные пути работают на адресе `https://OWNER.github.io/moscow-metro/`.

## Показатели

- Входы, выходы, сумма входов и выходов за один выбранный квартал.
- Возраст на 2026-10-23 и год открытия.
- Глубина под землёй; для наземных и надземных станций — 0.
- Расстояние по прямой до станции «Охотный Ряд».
- Абсолютный дисбаланс входов и выходов: `abs(in-out)/(in+out)*100`.

Размер означает площадь круга: `r = max(2.5, 26 * amplitude/100 * sqrt(w/max(w)))`. При прямой шкале `w=x`, при обратной `w=1/x`. Нулевые значения не участвуют в обратной шкале. Серый пунктир означает отсутствие значения хотя бы по одному выбранному показателю; доступный показатель продолжает действовать.

## Источники и ограничения

- [Яндекс Метро](https://yandex.ru/metro/moscow): геометрия, станции, названия, координаты; снимок 2026-10-23, версия `fa5d293`, 445 станций вместе с МЦД. Неофициальная визуализация; проект не связан с Яндексом.
- [Открытые данные Москвы, набор 62743](https://data.mos.ru/opendata/62743): выпуск 36 от 2026-10-23, 6756 строк. Пассажиропоток: 2021-Q1–2026-Q3. Для последнего периода сопоставлены 308 станций. Входы и выходы через турникеты не включают внутренние пересадки; сумма — проходы, не уникальные пассажиры.
- [Wikipedia, список станций метро](https://ru.wikipedia.org/wiki/Список_станций_Московского_метрополитена): даты открытия (309 станций), глубина (277). Значения с пометкой «нет в источнике» исключены. Wikipedia CC BY-SA 4.0.
- [D3.js](https://d3js.org/): ISC; лицензия в `dist/vendor/D3-LICENSE.txt`.

Сопоставление по названию и линии. МЦД не имеют данных о пассажиропотоке, возрасте и глубине в этой версии. Пропуски не заменены вымышленными значениями. Дата обновления снимка не равна периоду пассажиропотока. Подробности доступны из самой схемы.

Исходная геометрия Яндекс Метро включена по прямому запросу пользователя. Права на исходную схему принадлежат правообладателям; общая лицензия на неё этим проектом не предоставляется.
