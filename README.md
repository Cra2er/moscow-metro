# Moscow Metro

[Открыть схему](https://cra2er.github.io/moscow-metro/)

Интерактивная схема метро и МЦД на D3.js 7.9.0. Размер и светлота независимо кодируют показатели станций; доступны прямая и обратная зависимости. Кружки сплошные, без обводки. Исходные рамки пересадок убраны; соединения между станциями сохранены. Исходный цвет каждого маркера взят из схемы Яндекс Метро, включая станции сразу на нескольких диаметрах.

## Локально

Откройте `dist/index.html` либо выполните `python3 -m http.server 8080 --directory dist`. Данные и зависимости локальны; сборка приложению не нужна.

## Публикация

GitHub Actions публикует `dist` при push в `main`; workflow: `.github/workflows/pages.yml`. Относительные пути поддерживают GitHub Pages в подпапке `/moscow-metro/`.

## Показатели

- Пассажиропоток: кварталы метро/МЦК либо отдельный режим опубликованных суточных значений МЦД.
- Возраст станции, возраст в сети метро/МЦД, год открытия.
- Глубина, расстояние до «Охотного Ряда», расчётное время до него по сети.
- Количество платформ и путей, длина и ширина платформ.
- Интервал из снимка Яндекс Метро.

Площадь круга пропорциональна `x` или `1/x`: `r = max(2.5, 26 * amplitude/100 * sqrt(w/max(w)))`. Нули исключены из обратной шкалы. Исходные цветовой тон и насыщенность ветки сохраняются; HSL-светлота меняется от 0.84 к 0.25 по нормированному весу. Нет данных размера — исходный маленький кружок; нет светлоты — бледный цвет ветки. «Как на схеме» и «Цвет ветки» возвращают исходные радиусы и заливку.

## Источники и покрытие

Снимок данных: **2026-10-23**. 445 станций, включая 136 станций МЦД; 492 кружка на схеме. Станции с несколькими маркерами не считаются несколько раз в покрытии.

- [Яндекс Метро](https://yandex.ru/metro/moscow): геометрия, станции, названия, координаты, цвета маркеров, длительности связей и интервалы. Версия `fa5d293`. Время до центра — кратчайший путь по связям схемы, включая пешие пересадки, без ожидания поездов; интервал не является текущим расписанием.
- [Открытые данные Москвы, набор 62743](https://data.mos.ru/opendata/62743): выпуск 36, 6756 строк, I квартал 2021 — III квартал 2026. Последний квартал: 308 станций. Пассажиропоток — сумма входов и выходов через турникеты: проходы, не уникальные пассажиры; внутренние пересадки не включены. Данных МЦД в наборе нет.
- [Wikipedia, список станций метро](https://ru.wikipedia.org/wiki/Список_станций_Московского_метрополитена), списки четырёх МЦД и 438 индивидуальных статей: возраст — 445 станций, платформы — 433, пути — 123, длина платформ — 110, ширина — 94, глубина — 277. Для МЦД: возраст — 136, платформы — 125, пути — 96. У каждой станции есть ссылка на статью. Первоначальное открытие железнодорожной станции отделено от даты включения в МЦД. При известном только годе возраст помечен ≈. Неоднозначные диапазоны размеров показаны текстом и не участвуют в шкалах. Платформы и пути могут относиться ко всему станционному комплексу.
- Суточный поток МЦД — **17 станций**, отдельный режим «МЦД · опубликованные сутки». Источники: [публикация от 2025-09-23](https://live.mosmolodezh.ru/news/743) и [газета Metro от 2026-03-02 со ссылкой на Дептранс](https://www.gazetametro.ru/articles/22-novyh-gorodskih-vokzala-vozveli-v-stolitse-s-momenta-zapuska-mtsd-02-03-2026). Для станции используется более поздняя доступная публикация. Даты, типы дней и методики различаются: это не сопоставимый временной ряд. Дата публикации не означает дату измерения. Ссылка и дата доступны в карточке станции. Эти значения не смешиваются с квартальными; прогнозы не использованы. Полного сопоставимого ряда по всем станциям МЦД не найдено.
- [D3.js](https://d3js.org/): ISC, лицензия в `dist/vendor/D3-LICENSE.txt`. Wikipedia — CC BY-SA 4.0.

Пропуски не заменены нулями или оценками. Станции сопоставлены по названию и линии. Исходная геометрия Яндекс Метро включена по запросу пользователя; права на неё принадлежат правообладателям. Проект не связан с Яндексом и не предоставляет общую лицензию на его схему.
